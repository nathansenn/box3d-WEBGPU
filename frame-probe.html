What the model includes

Linear Euler–Bernoulli elements with consistent mass, axial extension, two bending planes and Saint-Venant torsion. Each node has three displacements and three small rotations. Dimensions and loads use SI units.

Large rotations, shear deformation, buckling, yielding, contact and bending rotary inertia are outside this model. The domain screen checks rotations, axial strain and the entire interpolated transverse slope; passing it alone does not establish physical accuracy. This study is uncalibrated.

Reading the result

Static analysis shows the equilibrium shape without advancing the dynamic run. Save and restore preserve the full dynamic state and study settings. The history records the most recent 600 samples.

Bending vibration starts in the first continuum cantilever mode; mesh and time discretization create measurable phase error. The one-element torsion case compares with its exact discrete midpoint phase. Magnification changes only the drawing.
