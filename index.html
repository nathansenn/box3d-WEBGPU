Compare, replay and inspect

The five material labs include 40 material profiles and 40 prepared experiments. Change the material and test controls, run the experiment, then use the timeline to inspect its recorded history. Export the selected settings and recorded frames as JSON run data.

Understand the models

The simulations use authored coefficients and reduced models for comparison. They are uncalibrated and do not provide certified engineering results. Each lab explains its model and limits. The interactive scene needs JavaScript and a browser with WebGL 2 or WebGPU support.

Project information is available in the BOX3D project repository. Read the project code license; individual asset notices are included with their files.
