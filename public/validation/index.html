How to read a row
  • Reference is the closed-form answer and the formula it comes from. Where it needs a number only the solver knows (a float32 mass), it uses that number.
  • Error is measured minus reference: a fraction of the reference when the tolerance is relative (a percentage, or “rel.” below 0.01%), otherwise in the unit of the quantity.
  • Tolerance is the one the linked test asserts for the same quantity. A case passes when the error is inside it.
  • An order is measured from two or three resolutions of the same problem: log(ecoarse / efine) / log(ratio).
  • A pass means the solver reproduces that textbook case to that tolerance. It does not make a scene built with the solver an engineering prediction: read “What is not validated” under each domain.
