## Material atlas

The runtime packages four derived Poliigon material tiles in a 2×2 atlas:

1. Weathered concrete
2. Clean galvanized zinc
3. Slate-blue woven upholstery fabric
4. Large-format honed grey stone

Two textures are loaded:

- sRGB albedo;
- linear normal RGB with roughness in alpha.

The preferred pair uses directly uploadable ASTC 6×6 KTX2 at a block-aligned 1008×1008 resolution. Its resident GPU chain stops at the last fully aligned 126×126 mip. The compatibility pair uses the complete RGBA8 KTX2 chain. If neither can be loaded, the renderer creates a deterministic procedural atlas so startup remains reliable.

Glass is generated by the PBR shader rather than baked into the atlas. The material uses a low roughness, raised dielectric F0, cool absorption tint, and strong angle-dependent Fresnel response. It stays in the opaque instanced pass for deterministic ordering and low draw-call overhead; this is reflective architectural glass, not a full refraction renderer.

## Concrete and glass break behavior

The material-failure simulation remains authoritative for breaking members and presentation damage:

- reinforced concrete uses progressive cover damage over a separate higher-capacity ductile rebar cage; each failed cohesive cell removes its local cover tile and emits two bounded physical spall fragments;
- soda-lime glass uses a narrow elastic envelope, negligible plastic creep, a framed vertical pane, a center-punch flaw, eight outward crack rays, disappearing local skin tiles, and three bounded shards per failed cohesive cell;
- the concrete and glass debris pools retain up to 192 live pieces through the final cinematic inspection instead of disappearing at the failure beat.
- material-specific strike VFX add hot metal scale, concrete dust and rebar sparks, or glass micro-shard glints without altering authoritative solver state;
- persistent aggregate and luminous crack-edge accents preserve crater and crack readability after the short-lived impact effects clear.

These fragments are deterministic presentation-scale debris driven by the authoritative lattice cell state. The comparative coefficients are normalized and are not calibrated constitutive data, FEA, or structural certification.

## Rebuild the derived textures

The source library location defaults to the discovered local Poliigon library. Override it when the library lives elsewhere:

```bash
POLIIGON_LIBRARY=/absolute/path/to/poliigon npm run build:poliigon-materials
```

The build script requires `ffmpeg` and `toktx`. It writes only the four derived KTX2 atlases under `public/textures/`; it does not copy the full source library into the repository.

## Acceptance checklist

1. Run `npm run test:webgpu` and confirm all WGSL pipelines plus the RGBA8 atlas upload pass through Dawn.
2. Run `npm run test:webgpu:metal` and confirm the ASTC pair uploads, samples, and remains perceptually aligned with RGBA8 on the Mac GPU.
3. Run `npm run test:native-wasm` and confirm two deterministic traversals of all 800 native stages.
4. Run `npm run test:material:100` for the 100-case fracture matrix.
5. Open each starred hero in a hardware WebGPU browser and inspect material scale, metal permanent set, concrete cover/rebar separation, bounded glass crack paths, retained debris, highlights, shadowing, and collision behavior.
6. Confirm the console contains no WGSL, bind-group, texture upload, or uncaptured WebGPU errors.
