The persisted v1.3/v1.9 reports remain useful for inherited paths, but the v1.9 tournament belongs to the supplied archive's lineage and `bench:fifth:gate` checks those files rather than rerunning them. Except for the dedicated Metal timestamp-query benchmark, CPU and Dawn results are not physical-GPU timing.

## Release evidence gaps

The rope qualification, current hot-path benchmark, upload-cache probe, native soak, and Metal quality/startup measurements are now persisted. `validate:v1.10` is the cross-platform release gate; Metal-only `validate:hardware` remains separate. Remaining acceptance work is a visible target-browser pass, one end-to-end native-loader-to-renderer browser check, and physical-GPU profiling of complex cloth/water/rope scenes. `bench:fifth:gate` is historical artifact consistency only, and a native Box3D speed claim still requires a defined native baseline and dedicated timing benchmark.
