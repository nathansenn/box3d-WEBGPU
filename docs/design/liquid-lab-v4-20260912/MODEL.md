# Liquid Lab V4 — measurements and repeatable comparisons

The Analyze workspace reads recorded fields from the existing 84 × 28 finite-volume model. It introduces no new fluid constitutive model. Profiles, viscosity scaling, pipe resistance and substrate behavior remain comparative, uncalibrated assumptions.

The section slider selects the nearest containing streamwise grid column along the 6 m bed. The displayed and exported position is that column's actual cell centre, measured from the inlet. Probe A, B and C rows are the containing cells for transverse coordinates −0.65, 0 and +0.65 m. The UI and exports give the actual row centres. A solid cell is labelled Solid, distinct from a dry fluid cell. CSV probe readings are empty inside solids.

Through-flow is the section integral of the recorded depth times recorded streamwise velocity: sum(depth × vx × cell width), in m³/s. Negative values mean upstream transport. This is a cell-centred field estimate, not the solver's inter-cell numerical flux. Display uses L/s. Probe depth displays mm; speed displays m/s. The profile plots bed elevation above the laboratory floor and recorded water depth; gray vertical columns indicate obstacles. Replay reads the selected historical frame, never the current evolving solver arrays.

Program duration is 6–60 s, default 18 s. A cutoff of zero is disabled. Other cutoff values stop pump supply and rainfall at that simulated time; drainage and infiltration continue. Internal stepping splits at cutoff, so a crossing time step cannot add a whole step of extra supply. Cutoff has no effect on a closed reservoir flume. A cutoff later than program duration is never reached during that program. Manual Stop supply retains the existing release event and can extend the recording for drainage.

A comparison starts three fresh models with the same seed and settings, varying only the displayed parameter. The form displays the actual values before execution. Out-of-range, non-finite and duplicate values are rejected. The model may start with a different volume when the changed input alters bed shape; the curves include time zero to make that distinction visible. Initial water level and fill inputs remain fixed.

The worker runs cases sequentially, at the same 1/120 s outer step and internal CFL stepping as the live model. Curves retain both endpoints with at most 302 samples per case; the interval is max(0.1 s, duration / 300). Study maxima inspect every outer tick, including the initial state. Saved-run library traces retain the existing sampled-metric format; their library summaries use recorded samples. The JSON analysis report retains the study's full tick maxima and measured hydraulic summaries. CSV contains SI units, actual section/probe coordinates, time, source/sink volumes, signed flow, all three probes and complete settings JSON.

Starting a comparison pauses the live experiment. It leaves that model and its recording unchanged. A user can subsequently run the live experiment independently. Cancel terminates the owned worker and retains completed cases; stale worker messages cannot update the workspace. Navigating away disposes the worker. Loading a candidate creates a fresh specimen. Saving a candidate uses the existing browser run library and preserves earlier runs. Unsaved comparison results are held in memory; export or save before reloading.

The generated mockup guides the interface and visible probe arrangement. It is not a simulation result. The existing depth-averaged solver does not resolve droplet breakup, sediment transport, overturning or shoe friction.
