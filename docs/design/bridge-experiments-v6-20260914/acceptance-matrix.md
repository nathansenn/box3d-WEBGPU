# Acceptance matrix

| Surface | Required evidence |
| --- | --- |
| Empty setup | Existing scan/duration choices and frozen controls; no fabricated data |
| Completed results | Setup collapses; five case rows remain together; explicit scan metadata |
| Measurement modes | Drop, lateral movement and lost connections use the actual corresponding samples and units |
| Time probe | Keyboard range control; all case readouts at the chosen recorded time; no carry-forward past a partial record |
| Case inspection | Numeric values, selected-only scaling, load settings and baseline actions remain usable |
| Cancel / persistence | Partial samples retained, truthful completion and rupture counts, restore after reload |
| Configuration | Editing the next scan does not relabel the recorded batch |
| Desktop / phone | Inspect actual rendered app, no horizontal overflow, reachable controls and visible focus |
| Validation | Relevant unit tests, typecheck and bounded compilation; record precise limits |
| Cleanup | Only disposable task tab/context closed; preserve user tabs and data |
